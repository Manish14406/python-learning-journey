# Python Learning Journey
This repository contains my Python learning journey and the programs I wrote while learning Python step by step.
I started with the basics and gradually moved into problem solving, data structures, OOP, error handling, file handling, and small projects. Most of the programs here were written while learning and practicing concepts rather than as polished production code.

## What I've Covered

### Python Fundamentals
* Variables and data types
* Input and output
* Operators
* Strings and string methods
* Lists and tuples
* Dictionaries and sets
* Conditional statements
* Loops and iteration
* Functions and recursion
* File handling
* Exception handling

### Practice & Problem Solving
I have included problem sets and practice programs alongside the concepts I learned. These helped me understand the concepts by actually writing and debugging code instead of only studying the theory.

### OOP
* Classes and objects
* Constructors
* Instance and class concepts

### DSA
A separate `DSA` folder contains the problems I have started solving while building my problem-solving skills.

### Small Projects
I've also experimented with a few small Python projects, including:

* Millionaire game
* News app
* PDF merger
* Other small practice projects
